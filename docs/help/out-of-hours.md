# What happens when hours run out?

For: Students, Parents · Topic: Hours and payments

Classes can’t be scheduled or logged until you add hours.

Also searched as: no hours, zero, balance, empty, run out.

Only the person who pays for the account can do this. If a parent pays for a student, the parent manages it.

Your tutor can’t schedule or log classes until you add hours, and nothing is charged for a class that couldn’t be logged. Buy a pack on Pricing, or turn on auto-refill so it doesn’t run out. We email you when you’re running low, unless you turned off **Low-balance alerts**.
